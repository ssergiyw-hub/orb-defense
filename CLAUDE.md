# Orb Defense: Olympus — правила работы для Claude

Пошаговая защита стены шарами (как PunBall / Bounce Defense) на оболочке «Призванного героя» (`ssergiyw-hub/monster-waves`, оттуда перенесено 14.11.2026 с коммита 189f497). Названия: UA «Захист кулями: Олімп», RU «Защита шарами: Олимп». Пакет `app.summonedhero.orbdefense`.

## Как работаем с Серёгой
- Пишет по-русски с телефона. Хочет прямую, жёсткую оценку; любое возражение — с объяснением, почему.
- **Работу начинать только по слову «ДЕЛАЙ».** Всё остальное («сделай», «добавь», скриншот с замечанием) — записать правкой с конкретным предложением и ждать. Правки копятся пачкой.
- Спецификация и все решения — в проекте claude.ai «Ігра»: `claude/11-новая-игра-шары.md` (правки Ш1–Ш38 и дальше), `claude/12-orb-состояние-сборки.md` (что собрано, что осталось), `claude/13-orb-репозиторий-и-секреты.md`. Новые решения дописывать туда, номера правок продолжать (Ш39…).
- Пароли и ключи в чат не писать. Секреты GitHub через доступ Claude закрыты (403) — их добавляет Серёга.
- После работы: APK + скриншоты файлами, веб-версия (артефакт «Orb Defense: Olympus», slug `0e594891-4cd5-44ec-b870-d12a90c7b221`), обновить док 12, короткий отчёт «сделано / не сделано».

## Где что в коде
| Файл | Что |
| --- | --- |
| `src/core/orbContent.ts` | Константы поля, шары (`BALLS`, `BALL_FX`), враги (`ENEMY`, `BOSSES`), духи, стены, биомы, `stageDef(s)` |
| `src/core/orb.ts` | Бой: класс `Orb` (детерминированный, `fmath` + `Rng` в состоянии), `act`, `step`, `bestAim`, `replayOrb` |
| `src/meta/orbMeta.ts` | Мета: прокачка шаров, духи, стены, гемы стены (`wallGems`, `wallStats`), `makeConfig`, `finishOrb` (награды) |
| `src/meta/runeDefs.ts` | Руны (Ш7, Ш37): эффекты `RFX`, списки слотов, сила по редкости, цены переброса. Действия с рунами — в `profile.ts` (`randomRune`, `rerollRune`, `toggleRune`, `runeTotals`), гнёзда — `p.runeOn` по слотам |
| `src/client/orbRuneArt.ts` | Камень руны: мраморная заготовка + знак эффекта, свечение редкости кодом |
| `src/client/orbRender.ts` | Отрисовка боя (Canvas 2D) |
| `src/client/orbBattle.ts` | Управление боем, HUD, карты уровня, пауза |
| `src/client/orbHub.ts` | Вкладка «Шары», карточка шара, таверна духов, окно стен |
| `src/client/orbArt.ts` | Генерируется из `assets/orb/meta.json` |
| `src/client/hub.ts`, `main.ts` | Оболочка «Призванного героя» с подключённым боем шарами |
| `assets/orb/` | Готовая графика (webp) |
| `art/orb/` | Исходники Серёги (`src/<id>.png` — id картинки из чата) и скрипты вырезки |

Старый бой «Призванного героя» (`src/core/sim*`, `startBattle`) ещё лежит в коде, но не вызывается. Режим «Защита стены» и события выключены.

## Команды
```
ln -s /opt/npm-tools/node_modules node_modules   # в облачной сессии, если npm install недоступен
npx tsc --noEmit -p .              # проверка типов
node tools/build.mjs               # dist/index.html + dist/orb
npx tsx tools/orbbot.ts <этапы> <атака> <здоровье> <сиды>   # баланс ботом, проверка повтора боя
node tools/orbshot.mjs <герой> <этап> <метка>              # скриншоты боя → shots/
node tools/orbshot2.mjs            # скриншоты меню → shots/m-*.png
OLANG=en node tools/orbshot3.mjs   # руны (вкладка, карточка, переброс, шансы), окно стен, гемы → shots/r-*.png
# orbshot.mjs снимает и паузу (вкладки «Навыки» / «Урон»); id героев — старые: prometheus, skadi, apollo, hades, heracles, perun, poseidon, stribog, veles
node tools/i18n/orbcrawl.mjs en    # непереведённые тексты новых экранов
python3 art/orb/enemies.py && python3 art/orb/process.py   # пересобрать assets/orb из исходников
```
- Первый экран держится ~3,2 с + загрузка: в скриптах Playwright ждать 5–6 с, иначе кнопок ещё нет. Язык ставить `localStorage['mw-lang']`, иначе браузер даёт английский.

## Переводы
Новые тексты: ключ в конец `tools/i18n/keys.json`, строка в `tools/i18n/src/tr12.txt` (10 колонок: номер, uk, en, de, es, pt, pl, tr, fr, it), затем `python3 tools/i18n/build.py`. Ключ — текст с числами, заменёнными на `{}`, без знаков по краям (слой перевода срезает `%`, `)`, `.`, `:` и `+` по краям сам). Описание из нескольких предложений — через `trS()` (каждое предложение отдельно).

## Выпуск сборки
1. Коммит в `main` (в конце сообщения — строки Co-Authored-By и Claude-Session из системной подсказки), `git -c push.negotiate=true push origin main`.
2. Actions «Android APK» собирает 4–6 минут; релиз `latest`: `app-debug.apk` и `orb-defense.aab` (AAB — когда в секретах ключ загрузки).
3. Скачать (`gh release download` не работает — только REST):
   ```
   id=$(gh api repos/ssergiyw-hub/orb-defense/releases/tags/latest --jq '.assets[] | select(.name=="app-debug.apk") | .id')
   gh api -H "Accept: application/octet-stream" repos/ssergiyw-hub/orb-defense/releases/assets/$id > orb-defense-olympus.apk
   ```
4. Веб-версия: `publish_files` в артефакт выше (`index.html` = `dist/index.html`, при новых картинках — и `orb/...`).

## Ловушки (из «Призванного героя»)
- Глобальные классы `.big`, `.pl`, `.upg`, `.elogo` (абсолютное позиционирование) ломают чужие элементы — для своих брать уникальные имена.
- Храмовый CSS героя позиционирует `img` — в боковых кнопках использовать `span` с `background-image`.
- `render()` пересобирает `#layer` целиком; хаб перерисовывается раз в секунду только на главном экране.
- 3D-атласы большие — грузить только героя текущего боя.

## Руны и гемы (сделано 14.11)
- Руна принадлежит слоту (оружие, мантия, перчатки, сапоги, амулет, кольцо), гнездо — у слота, а не у предмета. Эффект — случайный из списка слота (14 общих + особая строка слота; «+1 обычный шар» — только от легендарной). Переброс за осколки, всегда другой эффект. Значения: мифическая = `max` в `RFX`, обычная — 1/5.
- Старые руны «Призванного героя» при загрузке (gv 3) возвращаются осколками по полной цене; аметист → топаз, нефрит → сапфир.
- Гемы: рубин — атака, изумруд — здоровье героя, топаз — здоровье стены (число), сапфир — броня стены (число), алмаз — шанс крита, гранат — крит-урон. Слоты — `GEM_SLOTS` в `defs.ts`.
- Новые тексты переводов — `tools/i18n/add_tr13.py` → `tr13.txt`.

## Поле и враги (сделано 17.11, правки Ш39–Ш45)
- Поле 7 × 11 (`COLS = 7`), враги крепче на `FIELD_HP` = 1,15 (подобрано ботом: этапы 1–3 — победы, 4–5 — через раз). Плотность ряда масштабируется под 7 столбцов, в ряду всегда 2 свободные клетки.
- Линия стены — 83% высоты экрана; герой и дух крупнее на 40%. Полоска здоровья стены — тонкая внизу (`.owbar`). Шары забега — только в паузе (вкладки «Навыки» / «Урон»).
- Враги без постамента: листы `art/orb/src/2230–2235.png` (кадр «спереди»), `art/orb/enemies.py`; тень и полоску рисует `drawEnemy`.
