# Обработка картинок для игры

Картинки (герои, предметы, гемы, фон) генерируются нейросетью на белом фоне, потом здесь вырезаются и сжимаются
в WebP, который вшивается в `src/client/*Images.ts` как data URI. Исходники лежат в `art/`.

| Скрипт | Что делает |
| --- | --- |
| `cut_hero.py src out iters [protect] [extra]` | Вырезает героя с белого фона: контур + белые «карманы» внутри (между посохом и телом), свечение переводит в прозрачность. `protect` — прямоугольники, которые нельзя трогать; `extra.circles` — что добавить к фигуре |
| `cut_hero_v1.py` | Первая версия вырезки (для сравнения) |
| `viz.py`, `stats.py` | Показать маску / посчитать фон, чтобы подобрать `iters` |
| `cut_items.py` | Режет листы предметов (4 листа: обычные, редкие, эпические, легендарные) на 18 предметов по координатам |
| `tone_stones.py` | Перекрашивает камни на посохах по редкости (сдвиг HSV + свечение) |
| `remove_bg.py` | Убирает шахматный «прозрачный» фон, который бывает на сгенерированных картинках |
| `cut_ui.py` | Детали интерфейса из Meshy (правки 87–91): набор «лавовый камень» (баннер, восьмиугольная рамка, табличка, лавовая кнопка, желоб, квадратная кнопка), колесо, сундук в 3 состояниях, фон-пещера, иконки заданий → `art/ui/*.png` → `src/client/ui2Images.ts`. Исходные листы — `art/ui/sheets` |
| `save_b64.py name < base64` | Сохраняет картинку из base64 и чинит сбитые повторы в строке (так приходили файлы с Google Диска) |

Нужны Python 3, numpy, scipy, Pillow.
