# Защита стены (правки 112, 115) — исходники Meshy

- `wall.webp` — стена с воротами (text-to-image nano-banana-pro, прозрачный фон). В игру идёт `assets/wall/wall.webp` (обрезка по альфе, 900 px).
- `fire … sky.webp` — фоны 10 карт дня (9:16). В игру идут `assets/wall/bg_<id>.webp` 720×1290 (лес обрезан от рамки).
- Id задач Meshy — `tasks.json`. Порядок карт — `WALL_MAPS` в `src/core/content.ts` (одна карта на сутки по UTC).
